About Store API

Store API is a portfolio e-commerce application by Serkan: a production-style Spring Boot REST API, and this storefront built on top of that same public API.

What it is

Everything you see in the shop — products, prices, your cart, checkout and order history — comes from the REST API. The storefront has no private shortcuts: it calls the same endpoints any other client would, documented in the API reference.

It's a learning and portfolio project, built to show how a real online store fits together end to end, not a registered business.

What's under the hood

  • JWT authentication with access/refresh tokens and customer/admin roles.
  • A product catalog with admin-only management and public browsing.
  • Guest carts that convert into Stripe Checkout sessions, with webhooks updating each order's payment status.
  • DKK and EUR pricing; every order keeps the currency it was charged in.
  • MySQL with Flyway-versioned migrations, and a live health endpoint behind the header's status indicator.

Tech stack
